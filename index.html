TCP/IP Simulation

TCP/IP is the protocol responsible for routing messages around the Internet. This page generates everything you need to run a fun and informative simulation of TCP/IP in your classroom, for any number of students. We once ran this simulation with 200 students in a gymnasium! Everything happens in your browser: your list of names is never uploaded anywhere.

Your materials

The download is a single self-contained HTML file: open it in a browser and print it. It has one page of instructions for you, then one page for each participant.

How it works

The Internet is organized into networks. There is one top-level network (Network 0, the "backbone"), with smaller subnetworks attached to it, and smaller ones attached to those. In the simulation, each network is a circle of students, and messages are handwritten slips of paper passed from person to person to the right. Each student plays one of three roles:

  • Regular nodes are normal computers. They keep messages addressed to them and pass along the rest.
  • Gateway routers sit on two networks at once. When they receive a message for someone else, they decide whether it belongs on their subnetwork or on their main network, by looking at the start of the IP address.
  • Nameservers keep an address book. Before writing to someone, you must ask your nameserver for their IP address.

When you generate a simulation, participants are added one at a time. Each network fills up to the maximum number of nodes; after that, new participants join the smallest subnetwork below it, hanging off an existing participant who then becomes that subnetwork's gateway. IP addresses reflect this position: a participant's address starts with the address of the network they belong to. Nameservers are then assigned to groups of nearby participants, starting from the center. Gateways are never nameservers.

The output contains a teacher's guide (objectives, background, room setup with a map of the networks, a directory of every IP address, a lesson plan and a worked example) followed by a personalized instruction sheet for each participant. Here's an example.

Options

  • IP address length: how many components addresses have. Each level of subnetworks uses one, so a larger value allows deeper networks. If you get an "address space is full" error, increase this or the maximum nodes per network.
  • Maximum nodes per network: the largest circle of students. Smaller values make more, smaller networks.
  • Nodes per nameserver: how many clients each nameserver serves.
  • Randomize: shuffles the participants before placing them.
  • Graph size: the size of the network diagram.
  • Output file name: what the download is called.

Command line

This page does the same thing as the generate-tcp-ip-simulation Python package (source and documentation), which you can install with uv: 

% uv tool install tcp-ip-simulation
% generate-tcp-ip-simulation names.csv
